## Rules (unchanged, non-negotiable)

1. Identical brand name/URL/description per site everywhere.
2. Brand or naked-URL anchors ONLY — never "abonnement iptv"-style money anchors.
3. 1-2 platforms per site per day maximum — velocity kills.
4. Language-matched content on language platforms (FR posts on Overblog, etc.).
5. If a platform moderates IPTV brands: note, skip, never argue.
6. Every batch reports its URL table back → dashboard progress + verification.
7. Watch spam score per site on /links — 4+ point rise = pause and audit.
