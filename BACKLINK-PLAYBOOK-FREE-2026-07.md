# Free Backlink & Authority Playbook — Platform-Level (v2)

**Date:** 31 July 2026 · **Replaces the strategy-only plan with named platforms and exact actions.**
**Rule #1: zero paid platforms.** No link marketplaces, no Fiverr/BHW sellers, no PBNs, no "guest post packages" — in this niche those are the fastest route to suppression.
**Measured by:** referring domains per site on the dashboard (DataForSEO, already automated). Target: **+10 ref domains/quarter on primeiptv & smarters-live**, +5 on the others.

---

## TIER 0 — Entity & profile foundation (one-time per site, ~2 weeks, all free)

High-DA profiles that establish each brand as a real entity. Do once, correctly, identical NAP everywhere. Spread over days, never in one batch.

| Platform | Type | Note |
|---|---|---|
| Google Business Profile | DA 90+ citation | If a business address/profile is viable per brand |
| Bing Places | citation | free |
| Facebook Page | profile | one per site, real branding |
| LinkedIn Company Page | profile | company entry + link |
| X/Twitter, Pinterest, YouTube, TikTok | profiles | bio link → money page |
| **Crunchbase** | DA 90+ company profile | free tier, real link |
| **Product Hunt** | profile + future tool launches | launch the device-checker & legal-checker here (free) |
| **Trustpilot** | brand + reviews page | doubles as "brand + avis/reviews" SERP owner |
| About.me, Gravatar, Linktree/Carrd | bio hubs | link hub → money pages |
| **Issuu + SlideShare** | document sharing (dofollow-friendly) | upload the setup guides / legal guide as PDF with links |

**Per-country citations (pick 5–8 real ones per market, skip mass submission):**
- 🇫🇷 France: PagesJaunes, Hotfrog FR, Cylex FR, Europages, Justacoté
- 🇪🇸 Spain: Páginas Amarillas, Yelp ES, Cylex ES, Hotfrog ES, Europages ES (see Whitespark's Spain top-citations list)
- 🇳🇱 Netherlands: Telefoonboek.nl, Cylex NL, Hotfrog NL, Openingstijden.nl, **Startpagina.nl** (classic NL link directory — relevant category pages)
- 🇦🇱 Albania: keep light — Google/Facebook/Bing profiles only.

> Research consensus 2026: a **few real, relevant** citations help (NAP consistency + referral); mass generic directory blasts read as spam. 290-site lists exist — we deliberately use ~8 per market.

## TIER 1 — Web 2.0 network (dofollow link equity, ongoing, free)

2026 research: **WordPress.com, Blogger, Tumblr, Weebly, Issuu still pass dofollow equity** when the content is real. Medium/Substack/Quora/Reddit are nofollow → they go in Tier 3 (distribution), not here.

**The set per site (build once, then feed):**
- 1 WordPress.com blog · 1 Blogger blog · 1 Tumblr · 1 Weebly one-pager · Telegraph + Write.as for one-off guides

**Rules (from current best practice):**
- **3–5 Web 2.0 posts/month per priority site max** — sustainable pace, no spam-filter trigger
- **800+ words, original** per post (never duplicated across platforms)
- Each post: 1 contextual link to a money/tool page + 1–2 internal links within the Web 2.0 blog itself
- Rotate angles: device install guide / market explainer / troubleshooting / legality summary pointing to the checker

## TIER 2 — Journalist quotes = free editorial links from real news sites (the highest-value free links that exist)

This is the replacement for "buying" authority — reporters need experts, and answering well earns DA 60–90 editorial links.

| Platform | Cost | How |
|---|---|---|
| **Source of Sources (sourceofsources.com)** | 100% free, no account — just email signup | 1–3 daily emails of journalist requests; reply directly. From HARO's founder; strict on-topic rule (off-topic pitch = ban) |
| **Featured.com** | free plan = 3 answers/month | pick the 3 best-fit questions monthly |
| **Qwoted** | free tier | streaming/tech/consumer-tech beats |
| **SourceBottle** | free | US/AU/NZ heavy — still useful for EN pieces |
| **Help a B2B Writer** | free | B2B/tech content writers |
| **X/Twitter #journorequest #PRrequest** | free | FR journalists use it too (#journorequest France) |

**The pitch identity (critical for our niche):** never pitch as "IPTV subscription seller." Pitch as **"streaming-technology / cord-cutting cost expert"** — topics: TV-streaming costs in Spain/France/NL, cord-cutting trends, how to spot illegal IPTV vs licensed services, device compatibility. The legal-checker gives us a citable asset and a legitimate expert angle. 2–3 pitches/week, only on-topic.

## TIER 3 — Communities (nofollow links but real traffic + the brand-search signal Google actually weighs)

2026 reality: Reddit/Quora/Medium links are nofollow — their value is **distribution, brand searches, and being cited inside AI answers**. In our niche this loop is proven: iptvesp's Telegram cluster drives most of its clicks.

- **Telegram (our proven #1)** — scale the playbook: 1 public channel per market, pinned money-page post, cross-posting. Feed it weekly.
- **Reddit — careful mode:** many subs ban IPTV provider promotion and are heavily astroturfed. Never name-drop our sites in ban-risk subs. Play the **legal/compliance + device-help angle** (r/cordcutting, r/firestick, r/AndroidTV, country subs) and let the profile carry the link. Value-first, weeks of karma before any link.
- **Quora + Quora ES/FR** — answer "is IPTV legal in France/Spain", "best IPTV app for Firestick" with genuinely complete answers; link only where it adds value (their 2026 guidance verbatim).
- **Niche forums (signature/profile links, 5–15/month cap):**
  - 🇫🇷 CommentCaMarche, Les Numériques forums, forum.hardware.fr (strict — value first)
  - 🇪🇸 Forobeta (webmaster, dofollow-friendly), Htcmania, Mediavida (careful)
  - 🇳🇱 Tweakers.net (top NL tech community — very strict, pure value + profile link only)
  - Kodi/Android-TV/Firestick communities and Discords for the device-checker
- **Medium + dev.to + Substack** — republish (canonical-tagged or rewritten) guides for reach + AI-answer citations, not for equity.

## TIER 4 — Linkable assets & earning links passively (our unfair advantage)

2026 research is unanimous: **free tools are the #1 link magnet**. We already spec'd two:

1. **Device/app compatibility checker** (smarters-live) — after launch: submit to Product Hunt (free), AlternativeTo, tool directories; drop it as *the answer* in every "which app for my device" thread; offer it to the "best IPTV apps" listicle authors.
2. **"Is IPTV legal?" checker** (primeiptv) — the citable asset for Tier-2 journalist pitches and legality threads; media love a sourced legality-by-country reference.
3. **Embeddable badge** (phase 2): "Works on your device ✓ / Legal status: 🇫🇷" widget bloggers can paste → each embed = a link.
4. **Listicle outreach (free):** find "best IPTV / meilleur IPTV / beste IPTV" listicles ranking top-20, email the author a genuinely better entry (tool + guide). Listicle placements are 2026's highest-impact white-hat links.
5. **Broken-link building:** find dead IPTV-guide pages via their outdated listicles; offer our live equivalent.

## TIER 5 — Reclaim & mine (free, weekly, 15 min)

- **Unlinked mentions** — Google: `"iptvesp" -site:iptvesp.com` (per brand); set **Google Alerts + Talkwalker Alerts** (both free) per brand name. When found → short thank-you email asking for the link. Research: converts up to 5× better than cold outreach.
- **Competitor link mining** — we already pay DataForSEO (existing stack, not a new platform): pull competitors' referring domains monthly, filter to the **free, replicable** ones (forums, directories, Web 2.0, tool mentions), replicate only those. Supplement: Ahrefs' free backlink checker (top-100 links per domain, free).
- **GSC links report** — free ground truth on what Google already counts.

| Day | Action |
|---|---|
| Mon | 2 journalist pitches (SoS/Featured/Qwoted) + check Google Alerts |
| Tue | 1 Web 2.0 post (rotate site & platform) |
| Wed | 2–3 forum/Quora answers (rotate FR/ES/NL) |
| Thu | Telegram posts all channels + 1 Reddit value comment |
| Fri | 5 outreach emails: unlinked mentions / listicle / broken-link |
| Monthly | Competitor-link mining pass + 1 new linkable-asset improvement |

**Priority order for all effort:** 1) primeiptv 2) smarters-live 3) iptvesp 4) iptvned 5) iptvshqiptar (light) — **iptvpix: Tier 0 only until indexing recovery completes.**

## Safety rails (non-negotiable, grey niche)
- Anchors: ~50% brand / 25% naked URL / 15% generic / **≤10% exact-match**
- Velocity: caps above; never batches; spread everything over days
- Zero: PBNs, paid marketplaces, BlackHatWorld sellers, "DA90 guest post $30" offers
- Watch the dashboard **spam score** — if it rises 4+ points, stop and audit
- Every link on a page a human would actually read
